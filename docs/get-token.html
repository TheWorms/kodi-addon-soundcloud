Get your SoundCloud token

Obtenez votre jeton SoundCloud

For the TheWorms Kodi SoundCloud addon.

Pour le module SoundCloud Kodi de TheWorms.

1 Drag this button to your bookmarks bar Glissez ce bouton dans votre barre de favoris

This is a bookmarklet — a small piece of JavaScript saved as a bookmark. You only need to do this once.

C'est un bookmarklet — un petit script JavaScript sauvegardé comme favori. À faire une seule fois.

🎵 Get SoundCloud Token

Drag the orange button above into your browser's bookmarks bar. If you don't see the bookmarks bar, press Ctrl+Shift+B (Windows/Linux) or Cmd+Shift+B (Mac) to show it.

Glissez le bouton orange ci-dessus dans la barre de favoris de votre navigateur. Si vous ne voyez pas la barre de favoris, appuyez sur Ctrl+Maj+B (Windows/Linux) ou Cmd+Maj+B (Mac) pour l'afficher.

2 Go to SoundCloud and sign in Allez sur SoundCloud et connectez-vous

Open SoundCloud in this same browser and sign in with your account.

Ouvrez SoundCloud dans ce même navigateur et connectez-vous à votre compte.

Open soundcloud.com → Ouvrir soundcloud.com →

Verify your avatar appears in the top-right corner.

Vérifiez que votre avatar apparaît en haut à droite.

3 Click the bookmarklet Cliquez sur le bookmarklet

Once you're on soundcloud.com and signed in, click the 🎵 Get SoundCloud Token bookmark in your bookmarks bar.

Une fois sur soundcloud.com et connecté, cliquez sur le favori 🎵 Get SoundCloud Token dans votre barre de favoris.

A popup will appear showing your token, with a Copy button.

Une popup apparaîtra avec votre jeton et un bouton Copy.

Privacy note: Note sur la confidentialité : the bookmarklet runs entirely in your browser. The token is NEVER sent to any server — not to TheWorms, not to GitHub, not to anyone. It only goes from soundcloud.com to your clipboard. le bookmarklet s'exécute entièrement dans votre navigateur. Le jeton n'est JAMAIS envoyé à un serveur — ni à TheWorms, ni à GitHub, à personne. Il va uniquement de soundcloud.com vers votre presse-papier.

4 Paste into Kodi Collez dans Kodi

Open Kodi → SoundCloud addon settings → Account → OAuth token and paste the token there.

Ouvrez Kodi → paramètres du module SoundCloud → Compte → Jeton OAuth et collez le jeton.

Click Test OAuth token to verify it works.

Cliquez sur Tester le jeton pour vérifier.

Bookmarklet not working? Show manual instructions Le bookmarklet ne fonctionne pas ? Voir les instructions manuelles

If the bookmarklet doesn't work (some browser policies block them), follow this manual procedure:

Si le bookmarklet ne fonctionne pas (certaines politiques de navigateur les bloquent), suivez cette procédure manuelle :

  1. Open https://soundcloud.com and sign in.
  2. Press F12 to open Developer Tools.
  3. Click the Network tab.
  4. In the filter box, type: api-v2
  5. Reload the page with F5.
  6. Click any request in the list (e.g. me or featured-tracks).
  7. Scroll to Request Headers in the right panel.
  8. Find the line Authorization: OAuth XXXXXX.
  9. Copy only what comes after OAuth  (no leading space).
  10. Paste into Kodi addon settings → Account → OAuth token.
  1. Ouvrez https://soundcloud.com et connectez-vous.
  2. Appuyez sur F12 pour ouvrir les outils développeur.
  3. Cliquez sur l'onglet Network.
  4. Dans le filtre, tapez : api-v2
  5. Rechargez la page avec F5.
  6. Cliquez sur une requête (ex. me ou featured-tracks).
  7. Défilez jusqu'à Request Headers dans le panneau de droite.
  8. Trouvez la ligne Authorization: OAuth XXXXXX.
  9. Copiez uniquement ce qui suit OAuth  (sans espace au début).
  10. Collez dans les paramètres Kodi → Compte → Jeton OAuth.

Common mistake: do not copy the cookie named oauth_token (under Application → Cookies). It looks similar but is rejected by the API.

Erreur courante : ne copiez pas le cookie nommé oauth_token (sous Application → Cookies). Il ressemble beaucoup mais est rejeté par l'API.
