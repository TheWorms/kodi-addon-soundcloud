Get your SoundCloud token

Obtenez votre jeton SoundCloud

For the TheWorms Kodi SoundCloud addon.

Pour le module SoundCloud Kodi de TheWorms.

Easy method: Méthode facile : copy the snippet below, paste it into the SoundCloud browser console. It prints your token. No bookmarklet, no Network tab, just one paste. copiez le code ci-dessous, collez-le dans la console du navigateur sur SoundCloud. Il affiche votre jeton. Pas de bookmarklet, pas d'onglet Network, juste un copier-coller.

1 Go to SoundCloud and sign in Allez sur SoundCloud et connectez-vous

Open SoundCloud in Chrome or Firefox on your computer and sign in.

Ouvrez SoundCloud dans Chrome ou Firefox sur votre ordinateur et connectez-vous.

Open soundcloud.com → Ouvrir soundcloud.com →

Make sure your avatar appears in the top-right corner.

Vérifiez que votre avatar apparaît en haut à droite.

2 Open the browser console Ouvrez la console du navigateur

While on soundcloud.com, press F12 to open the Developer Tools, then click the Console tab.

Toujours sur soundcloud.com, appuyez sur F12 pour ouvrir les outils développeur, puis cliquez sur l'onglet Console.

Other shortcuts: Ctrl+Shift+I (Windows/Linux), Cmd+Option+I (Mac), or right-click anywhere on the page → Inspect.

Autres raccourcis : Ctrl+Maj+I (Windows/Linux), Cmd+Option+I (Mac), ou clic droit sur la page → Inspecter.

If Firefox shows a warning Si Firefox affiche un avertissement about pasting code in the console (a security warning), type allow pasting as instructed, then press Enter. After that you can paste. concernant le collage de code dans la console (un avertissement de sécurité), tapez allow pasting comme demandé, puis Entrée. Vous pourrez ensuite coller.

3 Copy and paste this snippet Copiez et collez ce code

Click the Copy button below, then paste in the console (Ctrl+V / Cmd+V) and press Enter.

Cliquez sur le bouton Copier ci-dessous, puis collez dans la console (Ctrl+V / Cmd+V) et appuyez sur Entrée.

// snippet will be injected here by JS

A popup will appear in the SoundCloud page with your token. Click the Copy button in the popup to copy the token to your clipboard.

Une popup apparaîtra dans la page SoundCloud avec votre jeton. Cliquez sur le bouton Copy dans la popup pour copier le jeton dans le presse-papier.

4 Paste into Kodi Collez dans Kodi

Open Kodi → SoundCloud addon settings → Account → OAuth token and paste the token there.

Ouvrez Kodi → paramètres du module SoundCloud → Compte → Jeton OAuth et collez le jeton.

Click Test OAuth token to verify it works.

Cliquez sur Tester le jeton pour vérifier.

Privacy note: Note sur la confidentialité : the snippet runs entirely in your browser on soundcloud.com. The token is NEVER sent anywhere — not to TheWorms, not to GitHub. It only goes from soundcloud.com to your clipboard, then to Kodi. le code s'exécute entièrement dans votre navigateur sur soundcloud.com. Le jeton n'est JAMAIS envoyé quelque part — ni à TheWorms, ni à GitHub. Il va uniquement de soundcloud.com vers votre presse-papier, puis vers Kodi.
Snippet not working? Show full manual procedure Le code ne fonctionne pas ? Voir la procédure manuelle complète

If for some reason the snippet doesn't work, the fully manual procedure uses the Network tab:

Si pour une raison ou une autre le code ne fonctionne pas, la procédure entièrement manuelle utilise l'onglet Network :

  1. On soundcloud.com (signed in), press F12.
  2. Click the Network tab.
  3. In the filter box, type: api-v2
  4. Reload the page with F5.
  5. Click any request in the list (e.g. me or featured-tracks).
  6. Scroll to Request Headers in the right panel.
  7. Find the line Authorization: OAuth XXXXXX.
  8. Copy only what comes after OAuth  (no leading space).
  9. Paste into Kodi addon settings → Account → OAuth token.
  1. Sur soundcloud.com (connecté), appuyez sur F12.
  2. Cliquez sur l'onglet Network.
  3. Dans le filtre, tapez : api-v2
  4. Rechargez la page avec F5.
  5. Cliquez sur une requête (ex. me ou featured-tracks).
  6. Défilez jusqu'à Request Headers dans le panneau de droite.
  7. Trouvez la ligne Authorization: OAuth XXXXXX.
  8. Copiez uniquement ce qui suit OAuth  (sans espace au début).
  9. Collez dans les paramètres Kodi → Compte → Jeton OAuth.

Common mistake: do not copy the cookie named oauth_token (under Application → Cookies). It looks similar but is rejected by the API.

Erreur courante : ne copiez pas le cookie nommé oauth_token (sous Application → Cookies). Il ressemble beaucoup mais est rejeté par l'API.
