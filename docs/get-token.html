Get your SoundCloud token

Obtenez votre jeton SoundCloud

For the TheWorms Kodi SoundCloud addon.

Pour le module SoundCloud Kodi de TheWorms.

Two methods below. Deux méthodes ci-dessous. The console snippet tries to find your token automatically. If it can't (SoundCloud sometimes keeps the token in their internal app state, out of reach for scripts), the manual Network-tab method always works. Both are documented here. Le code dans la console essaie de trouver votre jeton automatiquement. S'il n'y arrive pas (SoundCloud garde parfois le jeton dans son état interne, hors de portée des scripts), la méthode manuelle via l'onglet Network fonctionne toujours. Les deux sont documentées ici.

1 Go to SoundCloud and sign in Allez sur SoundCloud et connectez-vous

Open SoundCloud in Chrome or Firefox on your computer and sign in.

Ouvrez SoundCloud dans Chrome ou Firefox sur votre ordinateur et connectez-vous.

Open soundcloud.com → Ouvrir soundcloud.com →

Wait a few seconds for the page to fully load. Make sure your avatar appears top-right.

Attendez quelques secondes que la page charge entièrement. Vérifiez que votre avatar apparaît en haut à droite.

2 Open the browser console Ouvrez la console du navigateur

Press F12 — click the Console tab.

Appuyez sur F12 — cliquez sur l'onglet Console.

Firefox warning about pasting: Avertissement Firefox sur le collage : on first paste, Firefox shows "Don't paste code here" and asks you to type allow pasting. Type it, press Enter, then paste the snippet. (Chrome shows a similar warning, also need to type allow pasting.) au premier collage, Firefox affiche un avertissement et vous demande de taper allow pasting. Tapez-le, Entrée, puis collez le code. (Chrome affiche le même avertissement, même procédure.)

Cliquez sur Copier le code, puis dans la console : collez (Ctrl+V / Cmd+V) et appuyez sur Entrée.

You should see this in the console (one of the three cases):

Vous devriez voir l'un de ces trois cas dans la console :

  1. Best case — a popup appears in the page with your token and a Copy button. Also the token printed in green in the console.
  2. OK case — no popup, but the console prints [SC] Token found: 2-... in green. Copy from there.
  3. Failure case — console says [SC] No token found. SoundCloud keeps it out of reach for scripts — use the manual method below.
  1. Meilleur cas — une popup apparaît dans la page avec votre jeton et un bouton Copy. Le jeton est aussi affiché en vert dans la console.
  2. Cas OK — pas de popup, mais la console affiche [SC] Token found: 2-... en vert. Copiez depuis là.
  3. Cas d'échec — la console affiche [SC] No token found. SoundCloud le cache des scripts — utilisez la méthode manuelle ci-dessous.

4 Paste into Kodi Collez dans Kodi

Kodi → SoundCloud addon settings → Account → OAuth token → paste. Click Test OAuth token to verify.

Kodi → paramètres SoundCloud → Compte → Jeton OAuth → collez. Cliquez sur Tester le jeton pour vérifier.

Privacy: Confidentialité : the snippet runs entirely in your browser. Token never sent anywhere. le code s'exécute entièrement dans votre navigateur. Le jeton n'est jamais envoyé quelque part.

Manual method (always works)

Méthode manuelle (marche toujours)

If the snippet didn't find the token (3rd case above), follow this procedure. It's the same workflow the snippet tries to automate, but done by hand — and it always works because the browser doesn't hide network headers from you.

Si le code n'a pas trouvé le jeton (3e cas ci-dessus), suivez cette procédure. C'est le même workflow que le code essaie d'automatiser, mais à la main — et ça marche toujours parce que le navigateur ne cache pas les entêtes réseau.

  1. On soundcloud.com (signed in), press F12.
  2. Click the Network tab.
  3. In the filter box, type api-v2
  4. Reload the page with F5.
  5. Wait a few seconds, then click any request in the list (e.g. me, featured-tracks, track_likes, etc.).
  6. In the panel on the right, look for the Headers section.
  7. Scroll to find Request Headers.
  8. Find the line:
    Authorization: OAuth 2-XXXXXX-XXXXXXXX-XXXXXX
  9. Copy only what comes after OAuth  (the token itself, no OAuth prefix, no leading space).
  10. Paste into Kodi addon settings → Account → OAuth token. Click Test OAuth token.
  1. Sur soundcloud.com (connecté), appuyez sur F12.
  2. Cliquez sur l'onglet Network.
  3. Dans le filtre, tapez api-v2
  4. Rechargez la page avec F5.
  5. Attendez quelques secondes, puis cliquez sur n'importe quelle requête (ex. me, featured-tracks, track_likes, etc.).
  6. Dans le panneau de droite, cherchez la section Headers.
  7. Défilez jusqu'à Request Headers.
  8. Trouvez la ligne :
    Authorization: OAuth 2-XXXXXX-XXXXXXXX-XXXXXX
  9. Copiez uniquement ce qui suit OAuth  (le jeton, sans le mot OAuth, sans espace au début).
  10. Collez dans les paramètres Kodi → Compte → Jeton OAuth. Cliquez sur Tester le jeton.

Common mistake: don't copy the cookie named oauth_token (Application → Cookies). It looks similar but is rejected by the API. You want the Authorization request header, not the cookie.

Erreur courante : ne copiez pas le cookie nommé oauth_token (Application → Cookies). Il ressemble mais est rejeté par l'API. Vous voulez l'entête Authorization, pas le cookie.
