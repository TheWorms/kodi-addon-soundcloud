2 Go to SoundCloud and sign inAllez sur SoundCloud et connectez-vous

Open SoundCloud in this same browser and sign in with your account.

Verify your avatar appears in the top-right corner.

3 Click the bookmarkletCliquez sur le bookmarklet

Once you're on soundcloud.com and signed in, click the 🎵 Get SoundCloud Token bookmark in your bookmarks bar.

Une fois sur soundcloud.com et connecté, cliquez sur le favori 🎵 Get SoundCloud Token dans votre barre de favoris.

A popup will appear showing your token, with a Copy button.

Une popup apparaîtra avec votre jeton et un bouton Copy.

Privacy note: Note sur la confidentialité : the bookmarklet runs entirely in your browser. The token is NEVER sent to any server — not to TheWorms, not to GitHub, not to anyone. It only goes from soundcloud.com to your clipboard. le bookmarklet s'exécute entièrement dans votre navigateur. Le jeton n'est JAMAIS envoyé à un serveur — ni à TheWorms, ni à GitHub, à personne. Il va uniquement de soundcloud.com vers votre presse-papier.

4 Paste into KodiCollez dans Kodi

Open Kodi → SoundCloud addon settings → Account → OAuth token and paste the token there.

Ouvrez Kodi → paramètres du module SoundCloud → Compte → Jeton OAuth et collez le jeton.

Click Test OAuth token to verify it works. You should see "Token valid: <your username>".

Cliquez sur Tester le jeton pour vérifier. Vous devriez voir "Jeton valide : <votre nom d'utilisateur>".

Bookmarklet not working? Show manual instructions Le bookmarklet ne fonctionne pas ? Voir les instructions manuelles

If the bookmarklet doesn't work (some browser policies block them), follow this manual procedure:

Si le bookmarklet ne fonctionne pas (certaines politiques de navigateur les bloquent), suivez cette procédure manuelle :

  1. Open https://soundcloud.com and sign in.
  2. Ouvrez https://soundcloud.com et connectez-vous.
  3. Press F12 to open Developer Tools.
  4. Appuyez sur F12 pour ouvrir les outils développeur.
  5. Click the Network tab.
  6. Cliquez sur l'onglet Network.
  7. In the filter box, type: api-v2
  8. Dans le filtre, tapez : api-v2
  9. Reload the page with F5.
  10. Rechargez la page avec F5.
  11. Click any request in the list (e.g. me or featured-tracks).
  12. Cliquez sur une requête (ex. me ou featured-tracks).
  13. Scroll to Request Headers in the right panel.
  14. Défilez jusqu'à Request Headers dans le panneau de droite.
  15. Find the line Authorization: OAuth XXXXXX.
  16. Trouvez la ligne Authorization: OAuth XXXXXX.
  17. Copy only what comes after OAuth (no leading space).
  18. Copiez uniquement ce qui suit OAuth (sans espace au début).
  19. Paste into Kodi addon settings → Account → OAuth token.
  20. Collez dans les paramètres Kodi → Compte → Jeton OAuth.

Common mistake: do not copy the cookie named oauth_token (under Application → Cookies). It looks similar but is rejected by the API.

Erreur courante : ne copiez pas le cookie nommé oauth_token (sous Application → Cookies). Il ressemble beaucoup mais est rejeté par l'API.
